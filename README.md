# 🚀 Customer Churn Analysis & Predictive Modeling

> 📊 An end-to-end Data Analytics & Machine Learning project to **predict customer churn** and identify **$11.98M revenue at risk**

---

## 📌 📖 Project Overview

Customer churn is a major challenge for subscription-based businesses.  
This project combines:

- 🔮 Predictive Analytics (Machine Learning)  
- 📊 Business Intelligence (Power BI Dashboard)  

👉 Goal: Identify **at-risk customers** and provide **data-driven retention strategies**

---

## 🛠️ ⚙️ Tech Stack

### 👨‍💻 Programming & Analysis
- Python  
- Pandas, NumPy  

### 🤖 Machine Learning
- Scikit-learn  
  - Random Forest  
  - Logistic Regression  

### 📊 Visualization
- Power BI  

### 📐 Statistics
- SciPy (Chi-Square Test)  

---

## 📈 📊 Key Business Insights

- 💰 **$11.98M Revenue at Risk**  
  → Mostly from Month-to-Month contracts  

- 📌 **Top Churn Driver**  
  → Contract Type (*p < 0.05*)  

- ⚠️ **761 Customers Lost**  
  → Due to competitor switching  

- 🔐 **3x Higher Retention**  
  → With Tech Support & Online Security  

---

## 🤖 📉 Machine Learning Results

- 🎯 **Recall:** 0.81
